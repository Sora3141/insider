# インサイダー・ゲーム — 1台で遊ぶ会話と推理

1台のスマホ／PCを回して遊ぶ、4〜8人用の「インサイダー・ゲーム」パス＆プレイ版。
公式ルールに沿った進行（マスター公開 → 役職確認 → 質問タイム → 議論タイム → 2段階投票）をアプリが案内します。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/insider/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

- **役職**: マスター（全員に公開・お題を知っている）、インサイダー（正体は秘密・こっそりお題を知っている）、庶民（残り全員・お題を知らない）
- **流れ**: マスター発表 → 端末を回して長押しで役職確認 → 質問タイム（マスターに「はい・いいえ・わからない」で答えられる質問をしてお題を当てる） → 議論タイム（質問にかかった時間と同じ長さ） → 投票1（正解者はインサイダーか？） → 投票2（指差し） → 正体公開
- **勝敗**: 時間内に当てられなければ全員の負け。正体を公開した人がインサイダーなら庶民チーム（マスター含む）の勝ち、違えばインサイダーの一人勝ち
- **操作**: すべてタップ・長押しで遊べます。PC ではキーボードも使えます（Space 長押し：役職カード／お題の表示、Enter：次へ、P：一時停止）

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも遊べます。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

## Features

- 長押しで役職を表示し、指を離すと隠れる役職カード
- 質問タイムのリングタイマーと、マスター専用の「長押しでお題確認」
- 議論タイムは質問タイムにかかった時間と同じ長さ（公式ルールどおり）
- 投票1（正解者はインサイダーか？）→ 投票2（指差し）→ カードをめくって正体公開
- マスターの順番交代／ランダム、ジャンル選択、セッション中の勝利数記録
- 画面スリープ防止・サウンド・バイブレーション
- PC・タブレット向けの横長レイアウト（進行状況・プレイヤー一覧のサイドパネル）とキーボード操作

## Files

- `index.html` — アプリ本体（HTML/CSS/JS）
- `manifest.webmanifest` / `sw.js` / `icons/` — PWA（ホーム画面への追加・オフライン）
- `webapp-kit/` — 「アプリにする」「共有」ボタン（T.OF... 共通の部品）
- 設定は `localStorage` の `insider.v2` に保存（端末内のみ）
